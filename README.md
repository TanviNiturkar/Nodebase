# ⚙️ Engineering Highlights

## Directed Graph Execution

Workflows are represented as directed graphs.

Before execution, the engine performs a **Topological Sort** to ensure each node executes only after all of its dependencies have completed.

---

## Durable Execution

Instead of executing everything in-memory, every workflow runs through **Inngest**.

Benefits:

- Automatic retries
- Crash recovery
- Long-running workflows
- Reliable execution

---

## Real-time Updates

Node execution status is streamed using **Inngest Realtime**.

No polling required.

Users instantly see:

- Running
- Success
- Failed

---

## Context-based Data Passing

Each node contributes to a shared execution context.

Future nodes can access previous outputs using Handlebars templates:

```handlebars
{{previousNode.output}}
```

---

## Layered Authorization

tRPC procedures are organized into:

- Public
- Authenticated
- Subscriber-only

Database ownership is enforced using authenticated user IDs in every protected query.

---

## Secure Credentials

Connected API keys are:

- Encrypted before database storage
- Decrypted only during execution
- Never exposed to the frontend

# 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/nodebase.git

cd nodebase
```

Install dependencies

```bash
npm install
```

Create a `.env` file

```env
DATABASE_URL=
DIRECT_DATABASE_URL=

BETTER_AUTH_SECRET=

NEXT_PUBLIC_APP_URL=

GOOGLE_CLIENT_ID=
GOOGLE_CLIENT_SECRET=

GITHUB_CLIENT_ID=
GITHUB_CLIENT_SECRET=

POLAR_ACCESS_TOKEN=
POLAR_SUCCESS_URL=

ENCRYPTION_KEY=

INNGEST_EVENT_KEY=
INNGEST_SIGNING_KEY=

SENTRY_DSN=
```

Generate Prisma Client

```bash
npx prisma generate
```

Run migrations

```bash
npx prisma migrate dev
```

Start the application

```bash
npm run dev
```

Run Inngest locally

```bash
npx inngest-cli@latest dev
```
